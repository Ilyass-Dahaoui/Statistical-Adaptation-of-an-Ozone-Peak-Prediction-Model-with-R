# Statistical Adaptation of an Ozone Peak Prediction Model with R

This project focuses on developing a machine learning model to predict ozone peak levels using statistical methods in R. The goal is to adapt and enhance existing ozone prediction models to improve accuracy and reliability in forecasting high ozone concentration events.

##  Overview

Ozone peaks pose significant health and environmental risks. Accurate prediction models are essential for timely warnings and mitigation strategies. This project utilizes statistical techniques to adapt existing models, aiming to better capture the dynamics leading to ozone peaks.

##  Repository Contents

- **Azone-1.Rmd**: R Markdown file with code and methodology for adapting the ozone peak prediction model  
- **rapport ozozne (1).pdf**: Final report summarizing results, analysis, and conclusions

##  Methodology

The approach involves:

- **Data Collection**: Gathering ozone and meteorological data
- **Preprocessing**: Cleaning and preparing the dataset
- **Model Adaptation**: Using statistical models to improve prediction accuracy
- **Validation**: Evaluating performance with appropriate metrics

##  Getting Started

To reproduce or explore the analysis:

1. **Clone the Repository**  
   `git clone https://github.com/Ilyass-Dahaoui/Statistical-Adaptation-of-an-Ozone-Peak-Prediction-Model-with-R.git`

2. **Open the R Markdown File**  
   Use [RStudio](https://posit.co/download/rstudio-desktop/) or any R-compatible editor to open `Azone-1.Rmd`.

3. **Install Required Packages**  
   Make sure to install all packages used in the Rmd file (e.g., `dplyr`, `ggplot2`, `forecast`, etc.)

4. **Run the Analysis**  
   Knit or source the R Markdown file to reproduce the full analysis and results.

##  Results

The adapted model demonstrates improved performance in forecasting ozone peaks compared to baseline methods. Full analysis and visualizations are included in the accompanying PDF report.
